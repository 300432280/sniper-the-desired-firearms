### 4. `paginationPattern.template` — VERDICT: `/page/{N}/` (DB correct, R1 BROKEN)

**R2 method:** read `buildPaginatedUrl` line-by-line + simulate output + live-verify both URLs.

**Runtime code (catalog-crawler.ts:118-125):**
```ts
export function buildPaginatedUrl(baseUrl, pageNum, pattern) {
  if (pageNum <= 1) return baseUrl;
  if (pattern?.type === 'path') {
    const template = pattern.template || '/page/{N}';
    const stripped = baseUrl.endsWith('/') ? baseUrl.slice(0, -1) : baseUrl;
    return `${stripped}${template.replace('{N}', String(pageNum))}`;
  }
  ...
}
```

**Simulation (page 2):**

| baseUrl | R1 template `/shop/page/{N}/` | DB template `/page/{N}/` |
|---|---|---|
| `/shop/` | `/shop/shop/page/2/` (BROKEN) | `/shop/page/2/` (correct) |
| `/category/4022-firearms/` | `/category/4022-firearms/shop/page/2/` (BROKEN) | `/category/4022-firearms/page/2/` (correct) |

**Live probe 2026-05-13T08:46Z:**
- `GET https://shooterschoice.com/shop/shop/page/2/` -> **404**
- `GET https://shooterschoice.com/shop/page/2/` -> **200**

**Conclusion:** R1's template is a runtime bug. Template MUST be a suffix because `buildPaginatedUrl` always appends to baseUrl. DB's value is correct.
