**Attack:** Maybe R2's simulation of `buildPaginatedUrl` is wrong; maybe some other code path handles `/shop/page/{N}/`-style templates.

**R3 read of catalog-crawler.ts:118-125:**
```ts
if (pattern?.type === 'path') {
  const template = pattern.template || '/page/{N}';
  const stripped = baseUrl.endsWith('/') ? baseUrl.slice(0, -1) : baseUrl;

```
