# 34-Site Profile Audit — Progress Tracker

## Audit Process
For each site, follow `.claude/catalog-url-discovery-playbook.md` (6-phase process). For each site, the agent verifies:
1. WAF / access mechanism (re-detect, don't trust stale `wafType`)
2. Platform identification
3. Product count via API/sitemap (preferred over stream-page-count)
4. CatalogUrls — minimum overlap, walk every candidate
5. Pagination pattern (`query`/`path`/`offset-query`/`suffix-replace`)
6. Sort parameter (READ the actual `<select>` HTML, never guess)
7. Final dedupe + verify

After every site: write a one-shot `update-{site}.js`, run, verify, delete.

**CRITICAL playbook references**:
- Mistake 14: `paginationPattern.template` — `query` type uses param NAME only (`'page'`, NOT `'?page={n}'`), `path`/`suffix-replace` use uppercase `{N}` placeholder
- Mistake 12: Don't drop categories without walking them (look for gun lights/slings/scopes hiding in non-firearm categories)
- Mistake 11: The bug is often in the FILTER, not the selector
- Mistake 7: Try mobile UA before declaring a site dead
- Mistake 2: Read actual `<select>` HTML, never guess sort param names
